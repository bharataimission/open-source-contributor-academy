# Bharat AI Mission — Open Source Contributor Academy

**From open-source beginner to contributor building India's AI future.**

Welcome to the Open Source Contributor Academy by [Bharat AI Mission](https://bharataimission.org).

This is a hands-on learning pathway designed to help anyone become an open-source contributor. You do not need prior open-source experience or even a software development background to begin.

Our approach is simple: **learn by doing, contribute by collaborating, and grow by building together.**

## Why this Academy?

Open source is more than freely available software. It is a collaborative way to build, improve, share, and maintain technology.

India's AI future needs more than AI users. It needs people who can contribute to AI tools, datasets, Indian-language resources, evaluation benchmarks, documentation, and community-led innovation.

This Academy helps you take your first steps into that ecosystem.

## Start your journey

### Level 0 — Discover Open Source
Understand open-source principles, project communities, licences, and the many ways to contribute.

### Level 1 — Learn GitHub
Learn repositories, issues, commits, branches, forks, and pull requests through hands-on exercises.

### Level 2 — Contribute Without Coding
Improve documentation, report bugs, review examples, help with translations, and support communities.

### Level 3 — Learn Git and Collaboration
Work with local repositories, patches, branches, merge conflicts, code reviews, and collaborative workflows.

### Level 4 — Contribute to Real Projects
Find suitable issues, understand project guidelines, submit focused changes, and work with maintainers.

### Level 5 — Contribute to Open-Source AI
Apply your skills to AI tools, Indian-language datasets, models, evaluation, speech, OCR, and responsible AI.

Each level combines learning resources with practical tasks. Progress is based on demonstrated skills, not simply watching videos or reading articles.

## How to participate

1. Start with Level 0.
2. Follow the learning resources provided for each task.
3. Complete the corresponding GitHub exercise.
4. Submit your work and learn from feedback.
5. Progress towards making meaningful contributions to real projects.

## Who can participate?

- Students and educators
- Software developers and engineers
- AI and data practitioners
- Researchers and academics
- Designers, writers, translators, and documentation contributors
- Domain experts and anyone curious about open source

## Our principles

- **Learn by doing:** Every lesson includes practical work.
- **Everyone can contribute:** Not every contribution requires coding.
- **Collaborate openly:** Learn to give and receive constructive feedback.
- **Respect licences and attribution:** Follow the terms governing code, data, models, and other resources.
- **Build for India:** Help strengthen open-source AI and Indian-language technology.
- **Pay it forward:** Help the next contributor get started.

## Get started

**Your first task:** [How to Contribute to Open Source](https://opensource.guide/how-to-contribute/).

Read the guide, explore an open-source project you use, and identify one way you could contribute to it. We will turn this first exploration into a practical GitHub exercise as the Academy develops.
