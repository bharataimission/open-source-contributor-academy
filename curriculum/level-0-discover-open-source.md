# Level 0: Discover Open Source

**Your journey starts here.**

Welcome to the Bharat AI Mission Open Source Contributor Academy!

In this lesson, you will discover what open source means, explore how people collaborate on projects, and identify your first opportunity to contribute.

**No coding experience is required.**

## Learning objectives

By the end of this lesson, you will be able to:

- Explain open source in your own words.
- Identify different ways to contribute, including non-code contributions.
- Find an open-source project that interests you.
- Identify a practical contribution you could make to a project.

**Estimated time:** 30–45 minutes

**Prerequisites:** A GitHub account is recommended. You do not need to know Git or write code.

---

## Task 1 — Understand open source

Read: [How to Contribute to Open Source](https://opensource.guide/how-to-contribute/)

As you read, consider:

- What makes a project open source?
- Why do people contribute their time to open-source projects?
- How do contributors and maintainers work together?
- How can a beginner contribute without writing code?

### Your activity

Write a short explanation of open source in your own words.

Aim for 2–4 sentences. Do not copy the definition from the guide.

## Task 2 — Explore the beginner's journey

Read: [New to Open Source? Here's Everything You Need to Get Started](https://github.blog/open-source/new-to-open-source-heres-everything-you-need-to-get-started/)

Identify three things a beginner should check before contributing to a project.

For example, you might consider the project's contribution guidelines, community activity, or whether the project welcomes new contributors.

### Your activity

List three checks you would make before choosing a project.

## Task 3 — Discover contributions beyond code

Read: [Open Source Non-Code Contributions](https://github.com/readme/featured/open-source-non-code-contributions)

Think beyond programming. Open-source projects need people who can:

- Improve documentation and tutorials.
- Test software and report reproducible bugs.
- Translate content.
- Improve accessibility and design.
- Help other community members.
- Validate datasets and improve metadata.

### Your activity

Choose two contribution types that interest you. Explain briefly why you chose them.

## Task 4 — Find a project you care about

Visit [GitHub Explore](https://github.com/explore) and look for a project related to an interest you already have.

You could explore education, healthcare, Indian languages, AI, data science, accessibility, or developer tools.

Open the repository and inspect its README. Look for a `CONTRIBUTING` file, issue tracker, or other guidance for newcomers.

### Your activity

Record the following:

- Project name and repository URL.
- What the project does.
- Why it interests you.
- One possible way you could help.

You do not need to submit a contribution to that project yet.

## Task 5 — Prepare your first contribution

Before finishing, review your answers from Tasks 1–4.

Identify one small, achievable action you could take next. It might be correcting a documentation error, testing an installation guide, improving a translation, or exploring an existing issue.

Avoid making changes to someone else's repository without first checking its contribution guidelines.

For this lesson, keep your answers in a personal Markdown file or notes. Do not publish personal details or submit changes to an unrelated project.
